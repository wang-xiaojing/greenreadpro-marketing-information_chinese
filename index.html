GreenRead Pro - 高尔夫果岭坡度测量与推杆线路辅助

LiDAR 高精度测量 无需注册账号 测量数据仅保存在本机

让果岭坡度在现场“可视化”。

GreenRead Pro 是一款利用 iPhone / iPad 的 LiDAR 扫描仪与相机， 测量高尔夫果岭坡度并辅助推杆读线的应用。

只需将真实球位与旗位（旗杆）对准画面，并把设备姿态调整到水平， 即可将距离、高低差、Break（弯曲）、下坡方向和预计滚动线路直接叠加显示在相机画面上。

无需繁琐的账号注册，全部测量均在设备本地完成。 即使在信号较弱或无网络的球场，也可正常使用。

主要功能

⛳

LiDAR 坡度测量

基于 LiDAR 捕捉到的果岭 3D 形态估算坡度，并以箭头显示下坡方向。

🎯

点击放置球位与旗位

按压画面即可显示放大圆，精确对齐真实球位与旗位，也支持自动切换流程。

📏

距离与高低差

显示球到旗的 3D 直线距离（m / cm / yd），并清晰标注上坡（＋）与下坡（−）高低差。

🌀

Break（弯曲）分析

计算球的偏转量和方向（H=左 / S=右），并可根据果岭速度调整 Break 分配。

🟦

滚动线路与瞄准线

以蓝色曲线显示预计推杆轨迹，以红色虚线显示瞄准方向，读线更直观。

🧭

设备姿态仪表

通过 X / Y 仪表引导设备水平；当接近 0° 时自动 Hold，快速锁定测量结果。

📊

果岭断面图

以断面图展示球到旗的高低变化，不仅看数值，也能直观看地形趋势。

💾

设置备份与恢复

可将自定义设置导出为 JSON 并恢复；换机或重装后也能快速还原。

使用方式，仅需 3 步

1

放置球位

让真实球与旗都进入画面，使用放大圆十字对准球位。

2

放置旗位

同样使用放大圆十字对准旗位（旗杆），完成后将切换到测量显示。

3

调整姿态并确认

当仪表指针接近 0° 时会自动 Hold，即可查看线路与测量值。

※ 保持设备水平，并将球与旗尽量放在画面中央附近，可获得更稳定的测量结果。

适合这类用户

  • 在坡度难判断的果岭上，希望获得更明确读线依据的用户
  • 希望当场确认上坡 / 下坡对距离感影响的用户
  • 在练习轮中研究“坡度与 Break 关系”的用户
  • 在击球前需要快速掌握含高低差距离信息的用户
  • 想在推杆练习前后记录与复盘果岭趋势的用户
